# 【实验要求】

本项目采用软件模拟嵌入式多任务系统。系统包含两个独立任务：温湿度周期性采集任务、告警监测与报表输出任务。

## 系统全局变量说明：

temp：保存最新采集温度；

hum：保存最新采集湿度

alarm_flag：告警锁存标志，0 = 无未处理异常，1 = 曾经出现异常且还未上报

alarm_cnt：累计告警次数

## 任务 1：温湿度采集任务（周期：1 秒执行一次）

每 1 秒自动模拟采集一组温湿度数据：

温度范围：-10.0 ~ 50.0 ℃

湿度范围：0.0 ~ 100.0 %RH

将采集得到的温度、湿度更新到全局变量temp、hum。

阈值判断规则：温度＞40℃ 或者 温度＜0℃ 或者 湿度＞80% RH，判定本次采样异常。

如果本次采样判定为异常：将全局告警锁存标志 alarm_flag 设置为 1。

如果本次采样判定为正常：不修改alarm_flag的值（原有的告警标记保持不变，不会被正常数据自动清除）。

## 任务 2：监测告警与报表打印任务（周期：2 秒执行一次）

每 2 秒读取全局温湿度数据和告警锁存标志alarm_flag。

在控制台打印监测报告。

判断告警锁存标志：

如果 alarm_flag == 1：打印告警提示；累计告警次数alarm_cnt加 1；将alarm_flag清零（代表本次异常事件已经上报处理完毕）。

如果 alarm_flag == 0：打印状态正常。

每次打印报告时，输出当前温湿度值和累计告警次数。

## 系统终止条件

当累计告警次数 `alarm_cnt >= 5`，程序打印提示信息并退出。
